# CookieYes - Cookie Compliance Made Easy

## Company Description

CookieYes is a consent management platform that helps businesses comply with privacy laws like GDPR, CCPA, and LGPD.
It offers tools to display cookie banners, manage user consent, and automate compliance — used by over 1.5 million websites globally.
CookieYes is part of Mozilor Technologies and is a Google-certified CMP and IAB-registered framework provider.

## Target Audience

- Businesses that use cookies or track user data
- Website owners with EU/UK or US traffic
- Developers building compliant web applications
- Agencies managing privacy compliance for clients
- Non-technical users seeking a plug-and-play solution

## Main Value Proposition

CookieYes simplifies cookie compliance with automated scanning, custom banners, consent logs, and geo-targeting.
It ensures websites remain legally compliant across regions while preserving user experience.

## Key Features

- Customizable cookie consent banner
- Automatic cookie scanner and categorizer
- AI-based cookie classification
- Region-based banner display (GDPR, CCPA, etc.)
- Consent log storage and export
- Multilingual support
- Google Consent Mode v2 support
- IAB TCF v2.2 compliance
- Works with all major CMS and platforms
- Policy page generators
